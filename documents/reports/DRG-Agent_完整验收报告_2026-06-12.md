原报告中影响完整业务闭环的主要阻断项已经关闭：

本次真实运行还发现并修复了两个生产态并发问题：

- Celery 连续执行异步数据库任务时，旧实现会复用已关闭事件循环中的连接。
- 运行中任务取消后，工作进程可能把 `cancelled` 状态覆盖成 `completed`。

当前保留项主要是静态类型债务、前端包体积、测试警告、部分交付文档和生成文档的事实约束。这些问题不再阻断当前演示和核心业务闭环，但在正式生产交付前仍应处理。

## 3. 本轮修复范围

### 3.1 异步任务与运行稳定性

- `TASKS_EAGER` 生产默认值改为 `false`。
- 文档生成和测试用例生成拆分为“创建 pending 任务”和“Celery worker 执行”。
- 前端轮询真实任务状态，直到 `completed`、`failed` 或 `cancelled`。
- `start.sh` 增加 Celery worker 启动和日志输出。
- 健康接口使用 Celery inspector 探测实际 worker。
- 新增工作进程级异步执行器，复用同一个事件循环。
- 任务开始执行后立即提交 `running` 状态，避免长时间持有数据库事务。
- 生成完成前重新读取任务状态；已取消任务丢弃生成结果，不创建文档或测试用例。
- 取消接口立即持久化 `cancelled` 和结束时间，并发送 Celery revoke。

### 3.2 测试用例闭环

- 新增测试用例执行 API。
- 使用测试用例绑定的规则版本调用确定性 `GroupingEngine`。
- 保存 `actualResult`、`isPassed` 和 `executedAt`。
- 列表和详情均返回执行结果。
- 生成器始终用规则引擎计算预期结果，LLM 只参与标题和说明。
- 演示规则全量生成结果为 31 条：

- 修复导出响应字段不一致，前端可真实下载 Excel。
- 生成范围支持全部规则和全部 MDC。

### 3.3 文档系统

- 文档生成接口真实返回 pending 任务，不再同步等待 LLM。
- 前端等待任务结束后刷新文档列表。
- 新增 Markdown、HTML、PDF 三种下载格式。

## 9. 当前保留问题

### 9.1 重要但非当前功能阻断

1. Mypy 仍有 127 个错误，应逐步迁移为 SQLAlchemy 2.0 typed mapping。
2. 文档生成内容缺少严格的事实约束。真实 LLM 文档中可能出现不属于当前系统的能力描述或不准确日期，需要增加模板约束和生成后校验。
3. 任务步骤耗时仍是汇总后的近似分配，不是每个工作流节点的独立计时。
4. 执行日志尚未覆盖全部规则和配置管理操作。
5. 正在执行的 LLM HTTP 请求无法被 Celery solo pool 强制中断；当前实现保证取消状态和产物一致，但不能节省已经发出的模型调用成本。

### 9.2 一般工程问题

1. 前端主包超过 500 kB 警告，建议按页面拆包。
2. 前端测试存在 React `act(...)` 和 Router future flag 警告。
3. 部分课程要求的项目管理、配置管理、概要设计和演示材料仍未补齐。
4. 当前 PDF 为轻量文本导出，满足可下载和中文显示，但不等同于专业排版引擎。
5. 规则库仍为演示规模，不是完整国家 DRG 2.0 生产规则库。
