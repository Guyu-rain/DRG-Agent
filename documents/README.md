# documents/ —— 本地产物统一存储目录

本目录集中存放 DRG-Agent 运行期产生的**所有本地文件**，按内容分类，位置透明可见。
由后端配置项 `DOCUMENT_STORAGE_PATH`（默认 `./documents`）指向。

| 子目录 | 内容 | 产出方 |
|--------|------|--------|
| `generated/` | 虚拟文档系统对话式生成 / 提交的工程文档（Markdown），文件名为「标题_版本.md」 | 文档对话智能体 / 文档提交 |
| `exports/` | 测试用例等导出文件（`.xlsx`） | 测试用例导出 |
| `reports/` | 项目报告、验收报告等 | 人工 / 工具 |

说明：

- 文档不再按「需求/设计/测试…」类型分子目录，类型仅作为内容标签；所有生成文档扁平存放于 `generated/`。
- `exports/` 下的 `.xlsx` 为体积较大的二进制运行产物，已在 `.gitignore` 中忽略（保留目录结构）。
- 输入类数据（DRG 规则上传 `server/data/rules/`）与运行日志（`logs/`）仍保留在原位，不属于产物。
